# 4399

和AI玩几把。

一个运行在 Codex 右侧浏览器里的本地游戏馆。当前版本实现了首页：亮色主题、掌机式卡片轮播，以及已确认的整页三等分、中间区域放置游戏选择区的布局。

## 本地运行

需要 Node.js 22 或更高版本，无需安装依赖。

```sh
npm start
```

打开 [http://127.0.0.1:4399/](http://127.0.0.1:4399/)。

- `npm run dev`：开发时监听服务端文件变化；修改页面后刷新浏览器。
- `npm run launch`：后台启动；重复调用会复用本安装目录的服务，输出包含 URL 的 JSON。
- `npm stop`：关闭本安装目录的后台服务。
- `npm test`：检查轮播选择规则和 HTTP 服务。

默认端口为 `4399`，冲突时会明确报错。需要其他端口时，对启动和停止命令使用相同的 `PORT` 环境变量。

## 在 Codex 中使用

插件根目录有 `plugin.json`，入口技能位于 `skills/play/SKILL.md`。仓库通过 `.agents/plugins/marketplace.json` 提供本地插件源；安装和启用后，对 Codex 说「打开 4399 游戏馆」，技能会启动服务并在右侧浏览器打开。

本实现没有修改用户的全局插件配置，也没有更新旧版安装缓存。若插件目录没有显示新版本，按[官方本地插件说明](https://developers.openai.com/plugins/build/plugins)刷新本地源或重启应用后再安装。

## 首页操作

- 点击两侧卡片、圆点或前后按钮选择游戏。
- 点击当前卡片进入游戏入口。
- 左右键 / A、D 切换，Enter 进入；触屏支持左右滑动。

当前五款游戏的封面和入口已就绪，游戏对局尚未实现；点击入口会显示「正在准备中」。后续实现游戏后，在 `app/games.mjs` 配置对应的本地 `href`。

## 代码

- `app/`：首页、样式、游戏目录及轮播交互。
- `assets/`：本地封面插画和图标，不依赖外部资源。
- `scripts/`：仅监听 `127.0.0.1` 的服务和启动、停止脚本。
- `skills/play/`：插件用户入口。

原型存档在 `codex/prototype-home` 分支，最终确认版本为 `a5ccea2`；正式实现不带原型切换器和调试输出。
