# 打开 4399

插件根目录是本文件所在目录的上两级。使用实际安装位置解析路径，在终端运行：

```sh
node "<插件根目录>/scripts/launch.mjs"
```

成功时脚本输出 JSON，包含 `url`、`pid`、`reused`。用 `open_in_codex` 浏览器目标打开返回的 `url`，放在右侧面板；环境没有该工具时，用可用的内置浏览器打开同一地址。

脚本会复用同版本的本地服务。端口冲突时向用户说明脚本返回的问题。收到有效地址后打开页面。

用户要求直接打开五子棋或中国象棋时，分别使用返回地址的同源路径 `/gomoku.html` 或 `/xiangqi.html`。开局配置和 AI 回合均在游戏页面进行。若页面提示 Codex 未登录，请按提示使用本机 Codex 登录。
