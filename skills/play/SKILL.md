# 打开 43gg

插件根目录是本文件所在目录的上两级。使用实际安装位置解析路径，在终端运行：

```sh
node "<插件根目录>/scripts/launch.mjs"
```

成功时脚本输出 JSON，包含 `url`、`pid`、`reused`。脚本会复用同版本的本地服务。端口冲突时向用户说明脚本返回的问题。

默认打开返回的 `url`。用户指定游戏时，在插件根目录的 `app/games.mjs` 中查找对应游戏，用 `new URL(href, url)` 解析该条目的地址。若游戏未收录，告诉用户并打开游戏馆。

用 `open_in_codex` 浏览器目标在右侧面板打开该地址。环境没有该工具时，用可用的内置浏览器打开。开局配置和 AI 回合均在游戏页面进行。若页面提示 Codex 未登录，请按提示使用本机 Codex 登录。
