# 4399 五子棋规则

## 开局

- 棋盘开局为空，可选 9×9、13×13 或 15×15 个交叉点，默认 15×15。
- 黑棋先下，白棋后下。玩家可选择「我先下」「AI 先下」或「随机」，默认玩家先下。选择随机时，开局等概率决定谁执黑。

## 落子

- 黑白双方轮流在棋盘内的空交叉点落一子。第一手也可以落在任意空交叉点。
- 棋子落定后留在原处，除非悔棋。
- 黑白双方均无禁手，三三、四四和长连都允许。

## 胜负与平局

- 一方落子后，如果在横、竖或任一斜线上形成至少五颗连续的同色棋子，则该方立即获胜。六连及以上同样获胜，连线两端是否被堵住不影响判定。
- 棋盘全部下满且双方均未获胜时，判为平局。最后一手形成五连或更长的连线时，仍判落子方获胜。

## 悔棋

- 悔棋撤回玩家最近的一手，以及 AI 在这一手之后已落下的应手，回到玩家落子前的局面。玩家尚未落子时，没有可撤回的手数。
- 终局后也可悔棋。撤回后清除本局结果，由玩家继续落子。
