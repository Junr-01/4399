# 对弈工具

## `get_position` 查看局面

输入 `{}`，返回 JSON。

| 字段 | 含义 |
| --- | --- |
| `board` | 从最上方到最下方的 17 行。每行含首孔点号 `id`、首孔轴坐标 `q`、本行轴坐标 `r` 和占位字符串 `cells`。`.` 为空孔，数字为棋子所属席位。每行从左往右的点号和 `q` 均从首孔依次加一。 |
| `side` | 根据当前盘面将要走棋的席位。当前工具回合已经走棋时，此字段可能指另一席位。 |
| `lastMove` | 最近一着，含起点 `from`、终点 `to`、走方席位 `side`、完整路径 `path` 和防堵交换标记 `swap`。开局未走棋时为 `null`。 |
| `moveCommitted` | 为真表示你在当前工具回合已走棋。会话重试时，已走的着法继续生效。 |
| `legal` | 当前工具回合可用的着法，每项为起点和终点 `{ from, to }`。平移、连跳和防堵换位都使用相同格式，规则引擎确定路径。已走棋时列表为空。 |

轴坐标的邻孔差值为 `(1,0)`、`(0,1)`、`(-1,1)`、`(-1,0)`、`(0,-1)`、`(1,-1)`。目标营地的孔位已写在你的席位说明中。

## `move_piece` 走棋

输入 `{ from, to }`。起点、终点均为 0 到 120 的整数点号，直接使用 `legal` 中的一项。

- `success: true` 表示当前回合的着法已经提交。
- `success: false` 返回原因。回合内再次提交会收到「本回合已走棋。」已提交的着法保留。请求失效时，以新回合提供的局面为准。
