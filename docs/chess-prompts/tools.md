# 对弈工具

## `get_position` 查看局面

输入 `{}`。输出是 JSON。

| 字段 | 含义 |
| --- | --- |
| `fen` | FEN。六段依次为棋子摆放、轮走方、王车易位权、可合法吃过路兵的目标格、连续未动兵且未吃子的半回合数、完整回合编号。棋子按第 8 排至第 1 排、每排 a 至 h 排列。大写为白子，小写为黑子。`k/q/r/b/n/p` 依次为王、后、车、象、马、兵，数字代表连续空格。 |
| `check` | 为真表示下一着要走的一方被将军。你尚未走棋时指你，已走棋时指玩家。 |
| `lastMove` | 最近一着的 `from`、`to`、`side`（`white` 或 `black`）、`san`（标准代数记谱）。升变着还含 `promotion`。开局未走棋时为 `null`。 |
| `moveCommitted` | 为真表示你在当前 AI 回合已经走棋，包含会话异常后重试的情况。 |
| `legal` | 合法着法。每项含 `from`、`to`，升变着还含 `promotion`。被将军时只列应将走法。当前 AI 回合已落子时为空。 |

## `move_piece` 走棋

提交从 `legal` 选出的一着。必填 `from` 和 `to`，均使用小写标准坐标，例如 `e2`、`e4`。升变必须同时提供 `promotion`，取值为 `q`（后）、`r`（车）、`b`（象）或 `n`（马）。易位使用王的起止格，吃过路兵使用己方兵的起止格。

- `success: true` 返回「走棋成功。」该着已提交。
- `success: false` 返回失败原因。回合内再次提交会返回「本回合已走棋。」，保留已提交的着法。请求已失效时以新回合的局面为准。
