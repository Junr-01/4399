# 43gg 中国象棋规则

## 开局

- 棋盘固定为 9 列、10 行，共 90 个交叉点。黑方在上，红方在下，中间两行之间是河界，两方底线中央各有一个 3×3 的九宫。
- 双方各有 16 子，开局摆法如下。＋表示没有棋子的交叉点。
- 红方先走，黑方后走，双方轮流走一着。双方各走一着合为一个回合。

```text
車─馬─象─士─將─士─象─馬─車
＋─＋─＋─＋─＋─＋─＋─＋─＋
＋─砲─＋─＋─＋─＋─＋─砲─＋
卒─＋─卒─＋─卒─＋─卒─＋─卒
＋─＋─＋─＋─＋─＋─＋─＋─＋
│       楚河　漢界       │
＋─＋─＋─＋─＋─＋─＋─＋─＋
兵─＋─兵─＋─兵─＋─兵─＋─兵
＋─炮─＋─＋─＋─＋─＋─炮─＋
＋─＋─＋─＋─＋─＋─＋─＋─＋
車─馬─相─仕─帥─仕─相─馬─車
```

## 走棋

- 一着移动一枚己方棋子。走到空点即完成移动，吃子时由己方棋子占据对方棋子所在的点，并移除被吃的棋子。同方棋子不能相吃。

| 棋子 | 走法 |
| --- | --- |
| 帅／将 | 在己方九宫内横走或竖走一格。 |
| 仕／士 | 在己方九宫内斜走一格。 |
| 相／象 | 斜走两格，留在己方半场。斜线中点有子时不能走。 |
| 马 | 走「日」字：横两格竖一格，或竖两格横一格。朝走两格的方向，紧邻马的第一个点叫「马腿」。这点有子，该方向的两个落点就都不能走。例如正上方有子，马就不能走到上两格再偏左或偏右一格的位置。这叫「蹩马腿」。 |
| 车 | 沿横线或竖线走任意格，途中必须为空。 |
| 炮 | 沿横线或竖线走。走到空点时途中必须为空，吃子时起点与目标之间恰好有一枚棋子作炮架。 |
| 兵／卒 | 每着可向前走一格，过河后也可横走一格，始终不能后退。红方向上，黑方向下。 |

## 将军与胜负

- 攻击对方帅或将称为将军，被将军的一方必须立即应将。任何一着走完后，己方帅或将必须安全，双方帅将不能同列且中间无子（照面）。
- 轮到一方走棋时，如果没有合法着法，该方输棋。被将军时称为将死，未被将军时称为困毙。

## 重复局面与变着

| 术语 | 意思 |
| --- | --- |
| 将 | 这一着直接攻击对方的帅或将，也叫「将军」。 |
| 杀 | 这一着埋下杀招：下一着可以开始将军，有机会通过一次或连续将军将死对方。 |
| 捉 | 这一着形成得子的机会。例如车走到能吃掉对方一匹马、自己又不丢子的地方。若要靠交换或配合得子，要把对方的反击也算进去。 |
| 闲 | 不属于将、杀、捉。比如允许对方安全交换同类棋子，这种「邀兑」算闲。 |

- 同一方在循环中每一着都是将、都是杀或都是捉，连续循环三次，分别叫「长将」「长杀」「长捉」。计算循环时，走入循环的首着计入，首着若吃子则不计。
- 游戏在循环三次后自动裁决。如果只有一方长将，立即判该方负；长杀、长捉等按双方的着法裁定。帅将或兵卒单独长捉属于允许着法；与其他棋子配合形成捉子，或带出其他棋子新的捉子机会时，按「捉」处理。
- 棋例指定应变方时，由该方变着。双方原可不变作和时，前 25 回合（含第 25 回合）由红方变着；此后双方再重复两个回合则判和。
- 「变着」就是改走，打破原循环。应变方有两次走棋机会，继续原循环则判负。一方连续九回合在至少三个落点重复交替使用将、杀、捉中的至少两类着法时，也可能被要求变着，并须在两次机会内至少走一着「闲」。以游戏的裁决提示为准。

## 和棋

- 双方只剩帅、将、仕、士、相、象，且轮走方仍有合法着法时，判为和棋。
- 自然限着以连续 60 回合（双方合计 120 着）无吃子为基准。提和方在这段期间的将军着最多计入 10 着，超出的着数从计数中扣除。达到条件后，玩家可在自己走棋时申请和棋。

## 悔棋

- 悔棋撤回玩家最近的一着和 AI 已走的应手，回到玩家走棋前的局面，同时恢复当时的裁决和自然限着计数。玩家尚未走棋时，没有可撤回的着法。
- 终局后也可悔棋。撤回后由玩家继续走棋。
